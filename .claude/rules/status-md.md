# STATUS.md 기록 규칙

Sonnet은 작업 완료할 때마다 진행 상황을 STATUS.md에 기록한다. 목적: 대화 컨텍스트를 매번 다시 채우지 않고, 필요할 때만 파일을 읽어 상태 파악.

- 위치: PLAN.md/GUIDELINES.md/FIX_GUIDE.md와 같은 위치 (세트로 관리)
- 기록 내용: 완료한 작업 목록, 변경된 파일 경로, 테스트/시뮬레이션 결과 요약, 미해결 이슈, 다음 단계
- 코드 전문·전체 로그·스택트레이스는 옮기지 않고 결론만 요약 (원인/결과 한두 줄)
- 작업 단계 끝날 때마다 갱신. 새로 쓰지 않고 이어서 기록(append)하되, 완료되어 참조 불필요한 항목은 한 줄 요약으로 압축해 분량이 계속 늘지 않게 함
- 계획 이탈·막힌 부분은 "Opus 확인 필요" 항목으로 별도 표시
- 서브에이전트(sim-runner, impl-worker) 결과도 요약만 기록. 서브에이전트가 직접 STATUS.md를 수정하지 않고 본 세션이 기록
