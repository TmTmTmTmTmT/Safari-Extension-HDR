P0-2 EDR 램프

      

        왼쪽 흰색 패치는 CSS #fff(SDR white)다. 오른쪽 줄무늬는 왼쪽부터 1.0, 1.25, 1.5, 2, 3, 4, 6,
        8, 16이다. 줄무늬 중 SDR white보다 밝게 구분되는 가장 오른쪽 단계를 고른다.
      

      

        

        
      

      

      

      

        마지막 그리기 후 경과: -초. 밝기를 바꾼 뒤 30초 이상 기다린
        다음, 다시 그리기를 누르지 말고 선택한다.
      

      
      

        참조 HDR 이미지(선택): 파일을 열어 같은 화면에서 줄무늬와 밝기를 비교한다.

P0-4 비디오

      

        왼쪽은 원본 video, 오른쪽은 importExternalTexture + 셰이더 출력이다. 첫 프레임 후 1초는
        워밍업으로 버리고 최대 10초를 측정한다. G3용 수치는 "전체화면 측정" 버튼으로만
        얻는다(전체화면 진입 후 자동 시작, 종료 시 자동 해제). 창 모드는 "창 실행" 버튼이다.
      

      

        
        
      

      

      

        
        전체화면 overlay 배치(video 위 단일 캔버스)에서 ramp-1080p60, ramp-2160p60 각각 R0(rAF
        루프만, 캔버스 없음) → R2(rAF + EDR identity) → R3(rAF + EDR ITM) → V3(rVFC + EDR ITM,
        비교용)를 자동 실행한다(총 8 run, run 사이 1초). 끝나면 전체화면 안에서 끊김 질문이 뜬다.
        도중에 전체화면을 나가면 중단되고 완료된 run만 남는다. 전원 연결 + 밝기 중간에서 실행한다.
