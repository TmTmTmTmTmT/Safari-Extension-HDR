P0-2 EDR 램프

왼쪽 흰색 패치는 CSS #fff(SDR white)다. 오른쪽 줄무늬는 왼쪽부터 1.0, 1.25, 1.5, 2, 3, 4, 6, 8, 16이다. 줄무늬 중 SDR white보다 밝게 구분되는 가장 오른쪽 단계를 고른다.

참조 HDR 이미지(선택): 파일을 열어 같은 화면에서 줄무늬와 밝기를 비교한다.

P0-3 인코딩

각 행의 왼쪽은 셰이더가 캔버스에 0.5를 기록한 패치, 오른쪽은 CSS 색이다. 경계가 가장 안 보이는(일치하는) 쪽을 고른다.

CSS #808080 (0.5를 비선형 값으로 해석하면 일치)
CSS #BCBCBC (0.5를 선형 값으로 해석하면 일치)

P0-4 비디오

왼쪽은 원본 video, 오른쪽은 importExternalTexture + 셰이더 출력이다. 실행은 최대 10초이고 재생이 끝나면 함께 끝난다. 결과 표의 수치는 측정 조건(위 P0-5)과 함께 저장된다.
